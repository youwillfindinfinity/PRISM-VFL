Findings
--------
1. Root cause confirmed. The patient-level filter keeps the same PATIENTS at every
   site but not the same STAYS: B and C keep ~2,850 extra train stays (~600 val,
   ~575 test) that A does not have, so the per-site tables have different lengths
   and orders. Row i is almost never the same stay across sites (0-2% in train).
2. A's stays are a subset of B and C in every split (A_not_B = A_not_C = 0), so
   the stay intersection equals site A: 14,679 / 3,221 / 3,235 stays.
3. Patients have more than one stay: 14,679 train stays from 12,563 patients
   (1.17 stays/patient). The aligned cohort is 18,090 PATIENTS
   (12,563 / 2,765 / 2,762 = 69.4% / 15.3% / 15.3%).
